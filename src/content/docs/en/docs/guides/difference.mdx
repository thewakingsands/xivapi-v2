To save server resources, the XIVAPI service provided by FFCafe uses different update and storage methods.
As a result, some capabilities differ from the official XIVAPI service. The main differences are as follows:

<AnchorHeading id="language" level={3}>Supported Query Languages</AnchorHeading>

This service supports querying data in the following languages:

| Language | Code | Remarks |  
| --- | --- | --- |
| Simplified Chinese | `chs` | Default/primary language |
| Traditional Chinese | `tc` | |
| Japanese | `ja` | |
| English | `en` | |
| German | `de` | |
| French | `fr` | |
| Korean | `ko` | |

Data is merged from the latest processed version of each client. Availability of individual rows and translations can differ between clients.

<AnchorHeading id="sheets" level={3}>Supported Sheets</AnchorHeading>

This service does not support querying sheet data in subfolders (sheets with `/` characters in their names, mainly dialogue text).

<AnchorHeading id="game-versions" level={3}>Version Control</AnchorHeading>

Sheet requests use the latest version of data; the `version` parameter is ignored for those requests. Asset endpoints use separate published snapshots, as described in [Retrieving Assets](/en/docs/guides/assets/#limitations).

<AnchorHeading id="assets" level={3}>Assets</AnchorHeading>

This service currently supports only icons (`ui/icon/`) and maps (`ui/map/`) present in its published asset index, not arbitrary game files. See [Retrieving Assets](/en/docs/guides/assets/) for supported formats, caching and map composition.

Retrieving images by icon ID is also supported, with paths such as `/i/051000/051474.png` and `/i/051000/051474_hr1.png`. The `.png` suffix does not guarantee PNG bytes; use the response's `Content-Type`. See [Icon Paths](/en/docs/guides/assets/#icon-paths).
