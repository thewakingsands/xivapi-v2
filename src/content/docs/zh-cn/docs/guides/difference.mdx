为了节省服务器资源，FFCafe 提供的 XIVAPI 服务使用了不同的更新和存储方式。
因此，部分能力与 XIVAPI 官方的服务存在差异。主要差异点如下：

<AnchorHeading id="language" level={3}>支持的查询语言</AnchorHeading>

本服务支持查询以下语言的数据：

| 语言 | 代码 | 备注 |  
| --- | --- | --- |
| 简体中文 | `chs` | 默认/主要语言 |
| 繁体中文 | `tc` | |
| 日文 | `ja` | |
| 英文 | `en` | |
| 德文 | `de` | |
| 法文 | `fr` | |
| 韩文 | `ko` | |

数据基于每个客户端最新已处理版本的数据合并而来。具体数据行和译文的可用性可能因客户端而异。

<AnchorHeading id="sheets" level={3}>支持的表格列表</AnchorHeading>

本服务不支持查询子文件夹中的表格数据（名称中存在 `/` 字符的表格，以对话文本为主）。

<AnchorHeading id="game-versions" level={3}>版本控制</AnchorHeading>

查询表格数据时使用最新版本，`version` 参数无效。资源端点使用独立的已发布快照，具体限制请参阅[获取资源](/zh-cn/docs/guides/assets/#limitations)。

<AnchorHeading id="assets" level={3}>资源</AnchorHeading>

本服务目前仅支持已发布资源索引中的图标（`ui/icon/`）和地图（`ui/map/`），不支持任意游戏文件。输出格式、缓存和地图合成用法请参阅[获取资源](/zh-cn/docs/guides/assets/)。

同时兼容 V1 的图标路径，例如 `/i/051000/051474.png` 和 `/i/051000/051474_hr1.png`。其中 `.png` 后缀不保证实际返回 PNG，应以响应的 `Content-Type` 为准，详见[兼容 V1 的资源路径](/zh-cn/docs/guides/assets/#legacy-v1-paths)。
